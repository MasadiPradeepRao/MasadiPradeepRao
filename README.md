## 🚀 Featured Projects

### 1. ☁️ Automated Cloud Infrastructure Deployment & Monitoring

**Tech Stack:** OpenStack | Linux | HAProxy | NGINX | Prometheus | Grafana

- Deployed and managed cloud infrastructure and services using OpenStack.
- Automated provisioning of virtual networks, routers, and compute resources.
- Configured HAProxy and NGINX for load balancing and application traffic distribution.
- Implemented monitoring and visualization using Prometheus and Grafana.
- Used Apache Benchmarking to generate traffic and evaluate application performance and load-balancing behavior.
- Explored infrastructure scaling, availability, and resource utilization.

[View Project on GitHub](https://github.com/NSO-A.2)

### 2. ⏱️ Hourlog – Full-Stack Time Tracking Application

**Tech Stack:** Next.js | React | TypeScript | Supabase | PostgreSQL | GitHub Actions | Linux | NGINX

- Developed a time-tracking application for employees to record working hours and administrators to manage shifts and generate reports.
- Implemented role-based access control and secure database access using Supabase authentication and Row Level Security.
- Automated build and deployment workflows using GitHub Actions.
- Deployed the application in a Linux environment with NGINX as a reverse proxy.
- Managed environment variables, application configuration, and deployment secrets.
- Implemented operational checks and troubleshooting workflows to support reliable deployments.

[View Project on GitHub](https://github.com/TimeTrackerApp)

### 3. 📡 5G Massive MIMO Beamforming Optimization

**Tech Stack:** MATLAB | Python | TensorFlow | PyTorch | CNN | LSTM | QuaDRiGa | Genetic Algorithms

- Designed a hybrid CNN-LSTM and genetic algorithm approach for beamforming optimization in Massive MIMO systems.
- Evaluated wireless communication performance using QuaDRiGa channel models and 3GPP scenarios.
- Studied spectral efficiency, system sum rate, signal-to-noise ratio, and energy efficiency.
- Explored deep learning techniques for optimizing beamforming strategies in 5G networks.

[View Project on GitHub](https://github.com/Deep%20Learning%20MIMO)
